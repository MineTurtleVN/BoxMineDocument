# ⚙️ System GUI

> **Plugin:** DeluxeMenus, BoxMine-Core  
> **📁 Config:** `/plugins/DeluxeMenus/gui_menus/menu_main.yml`, `/plugins/DeluxeMenus/gui_menus/menu_warp.yml`, `/plugins/DeluxeMenus/gui_menus/menu_dungeon.yml`, `/plugins/DeluxeMenus/gui_menus/menu_huongdan.yml`, `/plugins/BoxMine-Core/gui/`  
> **Cập nhật:** 2026-04-29

---

System GUI là nhóm menu không chỉ bán đồ mà điều hướng người chơi đến hệ thống gameplay.

## 🧭 Menu Điều Hướng

| GUI | Mục đích | Người chơi dùng khi |
| --- | --- | --- |
| `menu_main.yml` | Hub chính | Mới vào server hoặc cần mở hệ thống khác |
| `menu_warp.yml` | Dịch chuyển | Cần tới mine, dungeon, khu farm hoặc khu shop |
| `menu_dungeon.yml` | Dungeon/PvE | Muốn farm mob, boss, dungeon item |
| `menu_huongdan.yml` | Hướng dẫn | Cần đọc hướng dẫn trong game |
| `menu_rank.yml` | Rank | Mua rank/VIP hoặc xem điều kiện |

## 🧩 BoxMine-Core GUI

`/plugins/BoxMine-Core/gui/` tồn tại trên server và dùng cho các GUI nội bộ của BoxMine-Core như chip, mine hoặc hệ thống nâng cấp nếu plugin bật menu tương ứng.
