# Documentation Findings

- Repository contains 26 Markdown pages across gameplay, economy, reward, combat, enhancement, social, UI, and reference folders.
- Current pages are partially Vietnamese but still use mixed English headings such as Overview, Reward, Mob Types, Config Reference, and GUI Menu.
- Content is mostly config-derived summaries. It lacks player-facing explanations, examples, tips, and FAQ sections.
- README is only a table of contents and needs a stronger entry point for new players.

## Rewrite Rules

- Translate structural language to Vietnamese.
- Preserve exact commands like `/rank`, plugin names like LuckPerms, and config paths.
- Add explanations around tables so the values are understandable without config knowledge.
- Add technical reference sections at the end for staff/admin readers.
