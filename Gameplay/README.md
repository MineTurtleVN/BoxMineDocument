# ⛏️ Gameplay - Vòng Lặp Chính

> **Nguồn config:** `/plugins/BoxMine-Core/`, `/plugins/DeluxeMenus/gui_menus/menu_rank.yml`, `/plugins/TurtleAFK/config.yml`

## ⚡ Tóm Tắt

Gameplay của Giant BoxMine xoay quanh đào mine, lên level, kiếm currency, mua rank, nâng cấp trang bị và chuyển sinh.

## 🧭 Route Đề Xuất

| Giai Đoạn | Việc Cần Làm |
| --- | --- |
| Newbie | Vào `/menu`, đi mine đầu, đào lấy EXP/Money/Blocks |
| Early | Mua rank đầu, đổi Coin, mở crate/key cơ bản |
| Mid | Dùng booster, gắn chip, farm dungeon lấy Mob Points |
| Late | Chuyển sinh nhiều lần, tối ưu rank/booster/item |
| End-game | Farm boss, dungeon item, item hiếm và PvP/event |
