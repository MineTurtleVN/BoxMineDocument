# 💎 Mine Và Boss Ore

> **Config:** `/plugins/BoxMine-Core/mines/`, `/plugins/BoxMine-Core/mines/Mine1.yml`

## Mine Chính

`Mine1` là Khu Mine I trong `World_I`:

| Thuộc Tính | Giá Trị |
| --- | --- |
| Display | `&6Khu Mine I` |
| World | `World_I` |
| Yêu cầu Thuật Thức | 0 |
| EXP/block | 2 |
| Money | 10-30$ |
| Blocks | 1-3 |
| Regen block | STONE |

## Boss Ore

Khi tổng block đào trong mine đạt `threshold: 1000`, Boss Ore 3x3 xuất hiện.

| Thuộc Tính | Giá Trị |
| --- | --- |
| HP | 500 |
| Damage limit/hit | 10 |
| Material | STONE |
| Spawn location | `67,111,4` |

## Mẹo

- Farm theo nhóm để Boss Ore xuất hiện nhanh hơn.
- Khi Boss Ore xuất hiện, ưu tiên phá trước để nhận reward nếu plugin có xử lý drop.
